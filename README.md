## 为什么用这个？

大多数人学音标的方式是死记硬背，效果极差。这个工具换了一条路：

- **输入任意单词**，立刻看到它的完整音标拆解
- **分色块展示**，元音、辅音、重音一眼区分，不再是一串看不懂的符号
- **每个音标都有说明**，告诉你它属于哪一类、怎么发音
- **点击即播放**，真人录音，听完就会

不用背表格，不用刷题——查几个常用词，音标规律自然就记住了。
